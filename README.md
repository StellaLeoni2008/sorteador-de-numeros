## 📌 Sobre

O *Sorteador de Números* foi desenvolvido como parte das atividades propostas no curso **Alura – Lógica de Programação: praticando com desafios**.

O principal objetivo do projeto foi praticar lógica de programação com JavaScript por meio da construção de uma aplicação capaz de gerar números aleatórios dentro de um intervalo definido pelo usuário.

A aplicação permite informar a quantidade de números que devem ser sorteados, além dos valores mínimo e máximo do intervalo. O sistema realiza o sorteio automaticamente, exibindo os resultados dinamicamente na interface.

O foco do projeto foi aplicar conceitos fundamentais de programação, validação de dados e manipulação da interface utilizando JavaScript.

---

## ⚙️ Funcionalidades
- Definição de intervalo mínimo e máximo
- Escolha da quantidade de números sorteados
- Geração aleatória de números
- Validação dos valores inseridos
- Atualização dinâmica da interface
- Reinício do sorteio
